Privacy Policy

Last updated: 16 October 2026

This policy covers the website at this address and MoneyGoesWhere Autopilot, a private tool used solely by the owner of the YouTube channel Money Goes Where? (@MoneyGoesWhere).

What the tool accesses

With the channel owner's own authorization through Google OAuth, the tool uses the YouTube Data API and YouTube Analytics API to: upload and schedule videos, set thumbnails and captions, update the privacy status of the channel's own videos, list public videos of other channels for content research, and read aggregate analytics (such as views and watch time) for the owner's own channel.

What we do not collect

The tool does not request, collect or store personal data of viewers or of any other Google users. It is not used by anyone other than the channel owner. This website does not use cookies, analytics or tracking.

Storage and sharing

OAuth tokens and analytics figures are stored only on the owner's own computer or private server, are never sold, and are never shared with third parties. Data obtained from Google APIs is used only to operate the owner's own channel.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent through the contact details on the channel's YouTube About page.
